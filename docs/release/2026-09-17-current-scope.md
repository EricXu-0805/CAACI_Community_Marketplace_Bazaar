# 当前产品范围与验收口径

更新：2026-09-17（Chicago）。本页同步产品范围，避免把旧路线图中的“未来功能”或历史候选当作当前状态。精确部署、平台回执及内部运营事项继续保存在负责人维护的发布总控；本页不替代它们。

| 范围 | 当前实现 | 独立验收边界 |
| --- | --- | --- |
| 网页发现与发布 | 卖家主页私信、按类型/分类发布、卖家名与模糊搜索、隐藏/撤销、兴趣与区域排序、最近浏览删除 | 推荐效果及持续容量需要实际数据，不承诺同时在线人数 |
| 网页聊天 | 私有照片/视频、未读/置顶/归档、媒体稳定显示、紧凑无红框输入区 | 双账号实体设备、系统键盘/相册和长期后台恢复 |
| 发布草稿 | 正式H5存储适配修复，编译产物覆盖保存、离开、刷新、恢复和丢弃 | 发布时核对线上版本并实测；禁用存储的环境仍可能仅在本次访问保存 |
| 英文内容 | 公开商品、动态和评论异步英文与原文切换；徽章及辅助文字随语言变化 | 翻译排队或失败须明示；私聊不进入公开翻译队列 |
| 位置 | 手动填写与设备辅助的大致街道检查区分 | 不是住址、身份、到场或交易安全保证；实体浏览器授权及GPS另验 |
| 界面 | 手机/iPad/Mac响应式、深层页面、图片预览、弹窗和克制过渡 | 用户再次反馈不适时重新调查，历史截图不关闭新反馈 |
| 微信与网站同账号 | 同一用户身份上的一次性码关联、双方证明、冲突与返回意图保护 | 已纳入当前优先范围；真实微信、旧身份恢复、隐私及平台配置满足前保持关闭 |
| 微信私有附件 | 照片审核候选受独立前后端开关控制 | 真实审核回调未验不能启用；视频审核尚未完成 |
| 小程序发布 | 开发构建、开发工具检查和上传分别记录 | 开发版不等于体验版通过或平台正式发布 |
| 品牌邮件 | 站内确认及重置邮件使用品牌双语模板 | Google自己发出的授权通知是另一类邮件，不能相互代替验收 |
| 官网与推广 | 社区导流入口、官网资源入口、分平台文案/海报/操作视频 | 素材、外部发帖、公开可见和平台推荐分别记录；链接互联不是账号合并 |

仍需保留的完整验收：实体设备与无障碍、真实提供方/多账号流程、管理员举报与申诉、告警送达与运营响应、持续混合负载、数据库＋Auth＋Storage文件的隔离恢复、真实供给与卖家响应。历史局部恢复或短时测试不能替代这些门槛。

原生iOS/Android按用户要求后置。未来CAACI/同城App深链接与统一身份也单独实施；公众号及其他小程序暂不纳入。会员、支付、物流和群聊不是本轮遗漏功能。

维护规则：新复现重新打开；代码、部署、可见行为、真机及平台审核分开；旧报告保留日期与证据，不将其勾选直接继承到当前版本。环境变量清单是配置合同，真机清单是测试计划，均不是实时完成看板。
