Eric（Guoyi Xu）参与 UIUC 学生及 CAACI 社区相关项目，现有工作包含二手平台 Illini Market、CAACI 官网、活动和未来商业权益设想。原始讨论希望让这些内容互相带来用户和持续交流，尤其服务新生安顿、生活问答、校友经验、求职交流与线下活动。

原对话“制定协同平台计划”形成过 V1 和 V2。Eric 随后要求在 Mac 接续，并要求阅读全部对话。已读取两轮文字、九张截图的可见内容和 V1→V2 文档修改，恢复 V2 全文。截图有语音转写，没有语音文件；没有把不可见语音作为事实。

原对话提出先做纯 UI 给合作方看。首轮据此制作了独立本地原型，随后 Eric 提出本轮修订：调研范围需要扩大，方案要足够详细以供另一台 VM 的 OMO 接手，产品不能像把不同网站模块拼在一起，也不能充满 AI 式文案。

## 用户明确提出的要求

| 要求 | 实施含义 |
| --- | --- |
| 不只参考一亩三分地与美卡论坛 | 比较社区、交易、活动和成熟工具产品的具体设计，不用一站模板包办所有页面 |
| 详细调查，再判断怎么执行 | 每项设计给出来源、适用任务、取舍和验证办法 |
| 界面精美、清楚、不繁杂、降低 AI 味 | 调整内容顺序、重复入口、列表密度、文案和状态，不仅换颜色字体 |
| 后面接口留好 | 先明确对象归属、稳定 ID、来源、权限和失败约定；业务未就绪时不展示假功能 |
| 可以开始后续迭代，有 GitHub 权限可动手 | 提交可审查的小批成果，保留现有工程和在途工作 |
| OMO 将在另一虚拟机运行 | 文档与样例必须可搬走，不依赖当前聊天、Mac 绝对路径或当前登录状态 |
| 需要可转发的 demo 网址 | 独立部署示例页面，普通访客可打开；用户自行转发 |
| 模型选型不急，主要由 AI 开发，Eric 主导 | 先解决产品与工程问题；不为站内 AI 增加无用途入口 |

## 当前采用的设计建议

这些是本次实施选择，尚无证据表明 Eric 已逐项认可。

- Illini Market 继续作为产品名称和社区核心；首轮不做重新命名或跨站品牌重塑。
- 首屏直接展示社区内容。主导航收敛为社区、二手、活动、消息、我的；旧 home/community 路径保留兼容。
- 五个话题板块：校园生活、二手与安顿、校友求职、活动搭子、本地优惠。板块管理话题；商品、活动、指南分别使用适合自己的详情。
- 主题类型和话题板块分开：例如“校友求职”下可以有提问或经验。公告等官方身份需要权限，不能让用户自选成为官方发布。
- 讨论用便于扫描的主题行；商品用图片、价格、状态；活动突出时间、地点、主办来源和报名状态。
- 对外 demo 使用合成示例人物、内容和素材；未来 Local Pass 等尚未可用能力留在方案和接口文件，不占普通用户首屏。
