## 正式工程与未验范围

正式社区代码位于独立 GitHub 分支；具体提交、PR、数据库和构建结果以 release/CURRENT_STATUS.md 及 release/P2_IMPLEMENTATION.md 为准。正式站没有合并这批改动，也没有执行生产数据库迁移。

本轮 demo 没有真实登录、多人共享数据库、通知发送、真实私信、报名或收费。管理员按钮只是演示，不代表权限实现。原型每帖关联一个对象；正式工程保留最多三件本人在售商品规则。
