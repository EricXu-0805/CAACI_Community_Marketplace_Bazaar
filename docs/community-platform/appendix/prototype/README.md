# 玉米地 Cornfield 公开演示站源码

BRAND.7 在 V4 静态原型（来源 4e459bd）上更新品牌与页面。需求见 [BACKLOG.md](../../BACKLOG.md) BRAND.7、[SPEC.md](../../SPEC.md) §3、§5、§9、§11、§14 和 D-01、D-24、D-35。方向 A「纸本书院」以 `appendix/visual/HOME.4/` 为对照：白色内容面、米色画布、细线、宋体区块标题、板块色条、亮暗两套 token，以及 BRAND.4 选定的单字「玉」印章。

首页在桌面显示五个板块加二手好物的 2×3 网格、去重后的全站最新和侧栏；手机按五个板块分节，每节最多三条。板块名依次为校园日常、落脚香槟、学长学姐说、找搭子、吃喝好店。列表按最后活跃时间排序时，行内时间与最后回复人也取最后活跃记录；切到新发布时显示发布时间。

顶部只保留一条全站说明：「演示站：内容均为虚构，操作只保存在这个浏览器」。各行不再重复附加虚构内容标签。标题和正文的 HTML `maxlength` 分别为 120、2000；提交处理独立检查相同上限，超长时保留输入、显示字段错误且不新增话题。浏览器正常输入会先按 `maxlength` 截断。回复正文上限 2000，私信上限 1000。字数沿用 HTML 与 JavaScript 的 UTF-16 长度规则。

保留原有 20 种路由状态；旧的 `category` 中文参数仍能打开对应板块。优惠卡已移除，旧 `#offer/o1`、`#offer/o2` 链接打开吃喝好店；发话题不能关联活动。活动列表有 CAACI、合作组织、学校、网友发起四种来源各一条虚构内容，网友活动与其唯一讨论互相链接。处理举报入口移到演示说明。发话题可关联自己在售的商品，支持草稿、回复、收藏、订阅、私信及举报的本地状态变化。

与正式版保留的差异（SPEC §14）：数据和操作只在本机浏览器，无后端、真实账号、登录、通知、报名或付款；商品私信只添加自己的消息，对方收不到；活动外部按钮只提示而不打开报名页面；任何访客可从演示说明试处理举报、替其他卖家修改商品状态。底部仍为「社区｜二手｜活动｜消息｜我的」，桌面各页共用演示站页头。页面只提供中文，保留 Cornfield 英文品牌名，不提供语言切换。内容时间是固定快照，新发的话题和回复才使用本机时间。内部存储 key 保留，结构版本升到 4，旧版操作记录会清空并提示。

本地可用任意静态服务器打开 `index.html`，不需要依赖安装或构建。运行：

```sh
node verify.js
```

`verify.js` 不部署。它检查品牌、五个板块、唯一顶部说明、禁用旧文案、HTML 与提交处理的 120/2000 边界、首页去重、五条核心流程、存储异常和全部 20 种路由状态。它在 Node VM 中运行，不能代替真实输入、焦点、排版或对比度检查。BRAND.7 的浏览器验收另测原生输入截断、绕过原生限制后的提交拒绝和边界接受，覆盖 390/1280、浅色/深色，并保留首页、板块、话题、发话题的 16 张截图；证据在 `~/work/evidence/BRAND.7/final-<UTC>/`。基线对照在 `~/work/evidence/BRAND.7/baseline/`，用 bd397ce 的产品文件配同一份新验证器，应因缺少新品牌而失败。

素材来源见 [assets/SOURCES.md](assets/SOURCES.md)。部署步骤由父任务按 BACKLOG BRAND.7 和 RUNBOOK §9 ④执行；部署用的配置不在此目录。本次只做源码与本地提交，预览、生产切换和旧部署回退记录仍由父任务及 Eric 完成。
