## 推荐 A

以下四条是判断。

1. 改动最小。A 的颜色、圆角和字号都来自生产 App.vue 的 :root，社区页的新样式只写 `var(--*)`。B 和 C 都要另起一套 token：已上线的二手、消息、我的这些页面要么跟着改，要么和社区页长得不一样。
2. 印章有连续性。生产的「集」印章是 Eric 2026-06-12 批准的方向（`app/src/components/icons/registry.ts` 文件头注释），A 只把字换成「玉」，几何不变。
3. 论坛任务靠标题。「待回答」的提问、置顶指南、找搭子的帖子大多没有图。C 的瀑布流里，炸鸡和蛋糕的照片最先抢到注意力，纯文字提问只能做成文字卡。冷启动时全站只有 20–60 帖，自带照片的帖子少，C 最吃亏。
4. 识别度。宋体字标和印章在 AI 模板和英文论坛里都少见。B 的黑白灰最不像 AI 产品，但也最像一个普通论坛，「玉米地」的地方感最弱。

B 和 C 各有一处值得借：B 在 1280 首屏能看完 6 张板块卡，如果 Eric 嫌 A 松，可以把 B 的「名称和说明并一行」和 32px 行高搬进 A。C 的图片方块和封面日期签适合二手页和活动页，这两页本来就靠图。

## 代码要改什么

三个方向都要做：

- 印章文件：替换 `app/src/static/logo-mark.svg`、`logo-mark-dark.svg`、`app-icon.svg` 和 `app-icon-192.png`、`app-icon-512.png`。稿里的「玉」是 SVG `<text>` 调用系统宋体，正式文件要转成轮廓路径，否则 Android 和 Windows 会换成别的字体。
- 徽章：「校园邮箱已验证」改用 success 色系。生产 `--success` #567345 放在 `--success-soft` #E4EADA 上只有 4.34:1，要新增文字色 `--success-text: #3F5A31`（6.28:1）。生产徽章现在用 `--campus-blue` #13294B，这是学校海军蓝，和 D-27「不用学校橙蓝配色」的方向不一致。
- 板块色：App.vue :root 新增 6 个 `--board-*` 变量，值见上表；暗色值另定。
- 价格：三份稿的价格都用正文色，生产代码的价格用 `--brand`。要让品牌色只出现在主按钮、当前态和链接上，价格样式要跟着改。
- D-04 的品牌色统一（P1.4：uni.scss 的 #C74A2F 和 `--shadow-cta`、`--shadow-brand`、`--shadow-fab` 里的 rgba(199,74,47)）三个方向都需要，不等 D-35。

只有 A：

- 新组件只用 App.vue 现有 token：字号 12/13/15/17/22/28、`--line-soft`、`--radius-sm`（8）、`--surface-alt`。`--font-serif` 只给字标、区块标题、页名和活动日期数字（SPEC §9.2）。
- 生产 `--font-hei` 补上 'Segoe UI' 和 'Hiragino Sans GB'。
- 暗色直接沿用生产 dark token，不新增工作。

只有 B：

- 新 token 组：#F5F5F5、#1F1F1F、#5C5C5C、#666666、#EBEBEB，圆角 4，盒子阴影。改 :root 会让全站一起变；只给社区页加作用域，同一个 App 里就有两套视觉。暗色值要重做。
- 楼层号需要稳定的回复序号。回复被删后楼层号保不保留要先定规则；保留的话要存序号列。
- 当前态和 tab bar 选中色从品牌色改成黑色。

只有 C：

- 新 token 组：白底、#F7F7F7、圆角 12、全胶囊按钮。暗色值要重做。
- 瀑布流要存首图宽高，封面比例夹在 3:4 到 4:3 之间；没图的帖子渲染文字卡。CSS columns 按列从上往下排，阅读顺序和时间顺序对不上，uni-app 里要用 JS 分列；`column-count` 在小程序端能不能用，没有验证。

## 稿子里做的取舍

- 站务帖上限：每个板块都有一条置顶指南，而 homepage.md 区块规则 5 规定站务账号的帖子在首页最多 3 条。所以校园日常、落脚香槟、吃喝好店的置顶由「站务」发；学长学姐说的置顶是校友「林学姐」的答疑帖，找搭子的置顶是志愿者「周宁」的感恩节拼车帖，由站务置顶。
- 最小字号：homepage.md 写置顶标签 11px，同一份文件又规定最小 12px。稿里所有标签都用 12px。
- 活动条目比规格高：每场活动多了一行来源标签（稿里写「CAACI 主办」「转自 CSSA」，正式写法按 SPEC §6.7.3 是「转发 · CSSA」），桌面侧栏每条约 84px（规格 64px），手机活动卡也高于 72px。来源标签是 D-10「不能乱」的关键，所以保留。
- 全站最新的头像：homepage.md 写左侧 28px 头像。A 按 V4 评审 A 方向的列表规格改成 20px 放进元信息行，B 用 40px 方头像，C 用卡片。
- 「本周 N 新帖」只在 N≥3 时显示：学长学姐说和吃喝好店本周各 2 帖，所以不显示。本周热议画的是全站 60 帖时达到阈值的状态。
- 未登录入口写「用校园邮箱加入」，没有照抄 homepage.md 的「用 Illinois 邮箱加入」，和 D-27 的徽章改名保持一致。
- C 桌面话题页的回复区在右栏内部滚动，`c-detail-1280.png` 只露出「共 3 条回复」；回复样式看 `c-detail-390-full.png`。
