  5. 保留已有未提交/已提交但附件失败/提交结果未知语义及账号代次保护。成功及部分成功都进入已提交ID的详情，避免当前板块/搜索隐藏刚发的内容；附件失败仍明确提示，不重建帖子或清除已提交媒体。
